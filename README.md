Payroll Bonus Calculator

Introduction
This project is a C++ Payroll Bonus Calculator developed for the Introduction to Programming assignment at Gauteng City College. I am an IT System Development student, and this project helps me apply my programming skills to calculate employee bonuses and total pay based on performance ratings and years of service.

Purpose
The program calculates an employee's bonus based on their performance rating and years of service. It then calculates and displays the employee's total pay.

Features
- Accepts employee details.
- Uses selection statements to calculate bonuses.
- Uses a loop to process employee information.
- Checks for invalid input.
- Displays a labelled payroll summary.

Technologies
- C++
- GitHub

How to Run
Compile and run the C++ source file using a C++ compiler.
